# Acervo Maker STL

Cloudflare Workers conectado ao GitHub:
- Diretório raiz: vazio (raiz do repositório).
- Build: npm run build
- Deploy: npx wrangler deploy
- Nome do Worker: stl-pro

A configuração wrangler.jsonc serve central-prime-clone/dist. Preserve essa pasta no Git, pois contém imagens e componentes usados no build.

Local: npm ci, npm run build, npm run dev.
